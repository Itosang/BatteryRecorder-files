## 变更

- 新增独立**“兼容设置”**页，包含：

  - **轮询获取息屏状态** (HyperOS / MagicOS / OriginOS 默认开启)
  - **轮询获取前台** App (HyperOS 默认开启)
  - **通知兼容模式** (OriginOS 默认开启)

## Changes

- Added a separate **"Compatibility Settings"** page, including:

    - **Polling for screen-off status** (enabled by default on HyperOS / MagicOS / OriginOS)
    - **Polling for the foreground app** (enabled by default on HyperOS)
    - **Notification compatibility mode** (enabled by default on OriginOS)
