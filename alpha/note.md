## Changes / 变更

- Fix server restart crash / auto-restart failure issue  
  修复 Server 重启崩溃 / 无法自动重启问题

After updating this version, please manually "**Stop service**" and then restart the service, or directly reboot the device. The fix will only take effect after completing this step.  
更新该版本后请手动“**停止服务**”，再重新启动服务，或者直接重启手机；完成上述操作后方可生效修复

Accessibility mode users may ignore this update.  
无障碍模式用户可忽略该更新
